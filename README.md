# queenshill.co

Static website for Queenshill Investments Ltd. Served by GitHub Pages from the `main` branch.

- `index.html` — the whole site (content, styles, scripts). Project data is in the `const P = [...]` array near the bottom.
- `assets/` — web-optimised photography and renders.
- `CNAME` — custom domain for GitHub Pages.

Every change is a commit; to roll back, revert the commit and push.
